# 🚀 Smart Task Manager Pro

### A Modern, Responsive & Interactive Task Management Web Application

Organize your day, prioritize your work, and track your productivity with **Smart Task Manager Pro** — a sleek task management application built with HTML5, CSS3, and JavaScript. Featuring a modern glassmorphism interface, dark mode, progress tracking, and browser-based data persistence, it makes managing everyday tasks simple and efficient.

## ✨ Features

### 📋 Task Management
- ➕ **Add Tasks** — Create tasks with relevant details.
- ✏️ **Edit Tasks** — Update existing task information.
- 🗑️ **Delete Tasks** — Remove tasks you no longer need.
- ✅ **Complete Tasks** — Mark tasks as finished.
- ↩️ **Undo Completion** — Move completed tasks back to pending.

### 🎯 Organization & Productivity
- 🗂️ **Task Categories** — Organize tasks by category.
- 🚩 **Priority Levels** — Set High, Medium, or Low priority.
- 📅 **Due Dates** — Assign deadlines to tasks.
- 🔍 **Live Search** — Find tasks quickly.
- 🎚️ **Smart Filters** — View All, Pending, or Completed tasks.

### 📊 Dashboard & Progress
- 📈 **Progress Tracking** — Visualize task completion with an animated progress bar.
- 📊 **Dashboard Statistics** — Get an overview of your tasks and productivity.
- 🕒 **Live Date & Time** — Stay updated with the current date and time.
- ☀️ **Dynamic Greeting** — Enjoy a greeting based on the time of day.

### 🎨 Modern User Experience
- 🌙 **Dark & Light Mode** — Switch between themes.
- 💎 **Glassmorphism UI** — A modern, elegant interface.
- ✨ **Smooth Animations** — Enjoy polished transitions and interactions.
- 📱 **Responsive Design** — Adapt to desktop, tablet, and mobile screens.

### 💾 Data Persistence
- 🔐 **Local Storage Support** — Save tasks in your browser so they persist across page reloads on the same browser and origin.

## ⚙️ Getting Started

Follow these steps to run Smart Task Manager Pro locally.

### Prerequisites

- A modern web browser such as Chrome, Edge, or Firefox.
- Visual Studio Code (optional).
- Live Server extension (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/Snehabelure419/Smart-Task-Manager-Pro.git
```

### 2. Navigate to the Project Folder

```bash
cd Smart-Task-Manager-Pro
```

### 3. Launch the Application

**Option A — Open directly**

Double-click `index.html` to open the application in your browser.

**Option B — Use VS Code**

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if needed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

That's it! No package installation or backend configuration is required for the current version.

## 💡 How It Works

1. **Create a task:** Add a task and enter its details.
2. **Organize your work:** Assign categories, priorities, and due dates.
3. **Manage your tasks:** Edit, delete, search, or filter tasks.
4. **Track progress:** Monitor completed and pending tasks on the dashboard.
5. **Customize your experience:** Switch between light and dark themes.
6. **Keep your data:** Tasks are stored in browser Local Storage, allowing them to persist across reloads in the same browser and origin.

> **Note:** Local Storage is browser-specific and does not synchronize tasks across devices. Clearing browser data may remove saved tasks.
