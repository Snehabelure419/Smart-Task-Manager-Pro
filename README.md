# 📋 Smart Task Manager Pro

A modern and responsive **Task Management Web Application** built using **HTML, CSS, and JavaScript**. It helps users organize daily tasks with an attractive interface, dark mode, progress tracking, and local storage support.

## ✨ Features

- ✅ Add New Tasks
- ✏️ Edit Existing Tasks
- 🗑️ Delete Tasks
- ✔️ Mark Tasks as Completed
- 🔄 Undo Completed Tasks
- 🔍 Search Tasks
- 🎯 Filter Tasks (All / Pending / Completed)
- 📂 Task Categories
- 🚩 Priority Levels (High, Medium, Low)
- 📅 Due Date Selection
- 📊 Dashboard Statistics
- 📈 Animated Progress Bar
- 🌙 Dark / Light Mode
- 🕒 Live Date & Time
- ☀️ Dynamic Greeting
- 💾 Local Storage Support
- 📱 Fully Responsive Design
- ✨ Glassmorphism UI
- 🎨 Smooth Animations


2. Open the project folder.

3. Double-click `index.html`

OR

Open with **VS Code** and use **Live Server**.
